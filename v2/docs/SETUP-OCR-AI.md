# เปิดใช้ชั้น OCR และ AI — ทำทีละขั้น

เอกสารนี้บอกวิธีตั้งค่าสองชั้นที่ต้องใช้กุญแจ
ทำครั้งเดียวจบ ไม่ต้องทำซ้ำ

**ยังไม่ทำก็ใช้ระบบได้ปกติ** — ชั้นกรอบกับตัวอ่านอัตโนมัติทำงานอยู่แล้ว
ชั้นที่ยังไม่ได้ตั้งค่าจะถูกข้ามไปเงียบ ๆ ไม่ทำให้อะไรพัง

ทำชั้นไหนก่อนก็ได้ ไม่ต้องทำทั้งสองอย่าง

---

## ชั้น OCR — ฟรี (แนะนำให้ทำก่อน)

ใช้ Google Drive แปลง PDF สแกนเป็นข้อความ
**ฟรี ไม่ต้องผูกบัตร ไม่ต้องเปิด billing** เพราะเป็น Workspace API
(ระบบนี้ใช้วิธีเดียวกันอ่านสลิปธนาคารอยู่แล้ว)

### 1. สร้างโปรเจกต์ที่ Google Cloud

ไปที่ https://console.cloud.google.com/

- กดเมนูโปรเจกต์ด้านบน → **New Project**
- ตั้งชื่ออะไรก็ได้ เช่น `kola-erp-ocr` → **Create**

### 2. เปิดใช้ Google Drive API

- เมนูซ้าย → **APIs & Services** → **Library**
- ค้นหา `Google Drive API` → กดเข้าไป → **Enable**

### 3. ตั้งหน้าขอสิทธิ์ (OAuth consent screen)

- **APIs & Services** → **OAuth consent screen**
- เลือก **External** → **Create**
- กรอกเท่าที่บังคับ:
  - App name: ชื่ออะไรก็ได้ เช่น `KOLA ERP`
  - User support email: อีเมลตัวเอง
  - Developer contact: อีเมลตัวเอง
- **Save and Continue** ไปเรื่อย ๆ จนจบ (ข้าม Scopes ได้)
- ที่หน้า **Test users** → **Add Users** → ใส่อีเมล Google ที่จะใช้เก็บไฟล์ชั่วคราว
  **ข้อนี้สำคัญ** ถ้าไม่ใส่จะขึ้นว่าแอปยังไม่ผ่านการตรวจสอบแล้วใช้ไม่ได้

### 4. สร้าง OAuth client

- **APIs & Services** → **Credentials** → **Create Credentials** → **OAuth client ID**
- Application type: เลือก **Desktop app** (สำคัญ — ห้ามเลือก Web application)
- ตั้งชื่อ → **Create**
- จะได้ **Client ID** กับ **Client Secret** มา คัดลอกเก็บไว้

> เลือก Desktop app เพราะสคริปต์เปิดเซิร์ฟเวอร์เล็ก ๆ ที่ localhost รอรับรหัส
> และใช้พอร์ตแบบสุ่ม — Desktop app ยอมรับ localhost ทุกพอร์ตอยู่แล้ว
> ไม่ต้องไปตั้ง redirect URI เอง

### 5. ขอ refresh token

```bash
cd v2
npx tsx scripts/google-oauth.mts <CLIENT_ID> <CLIENT_SECRET>
```

- เบราว์เซอร์จะเปิดให้อนุญาตสิทธิ์ (ถ้าไม่เปิดเอง ให้คัดลอกลิงก์ที่ขึ้นในหน้าจอไปวาง)
- เลือกบัญชี Google → ถ้าขึ้นเตือนว่า "Google hasn't verified this app"
  ให้กด **Advanced** → **Go to ... (unsafe)** — ปลอดภัย เพราะเป็นแอปที่เราสร้างเอง
- อนุญาต → หน้าเว็บขึ้นว่าสำเร็จ → กลับมาดูที่หน้าต่างคำสั่ง

จะได้ค่า 3 บรรทัดมา เอาไปใส่ `.env.local`:

```
GOOGLE_OAUTH_CLIENT_ID=...
GOOGLE_OAUTH_CLIENT_SECRET=...
GOOGLE_OAUTH_REFRESH_TOKEN=...
```

> สคริปต์ขอสิทธิ์แค่ `drive.file` คือเห็นเฉพาะไฟล์ที่แอปนี้สร้างเอง
> ไม่เห็นไฟล์อื่นใน Drive และไฟล์ที่อัปไปถูกลบทิ้งทันทีหลังอ่านข้อความเสร็จ

### ถ้าติดปัญหา

| อาการ | สาเหตุ / ทางแก้ |
| --- | --- |
| `ได้ access_token แต่ไม่ได้ refresh_token` | เคยอนุญาตไปแล้ว — ถอนสิทธิ์ที่ https://myaccount.google.com/permissions แล้วรันใหม่ |
| `Error 403: access_denied` | ยังไม่ได้ใส่อีเมลตัวเองใน **Test users** (ขั้นที่ 3) |
| `redirect_uri_mismatch` | เลือก client เป็น Web application — ต้องเป็น **Desktop app** |
| `Drive OCR ใช้โควตาเกิน` | ยิงถี่เกินไป รอสักครู่แล้วลองใหม่ |

## ชั้น AI — มีค่าใช้จ่าย

อ่านได้ทั้งไฟล์สแกนและไฟล์ปกติ เข้าใจตาราง ไม่ต้องลากกรอบ

### 1. ขอ API key

- ไปที่ https://console.anthropic.com/settings/keys
- สมัคร/เข้าสู่ระบบ → **Create Key** → คัดลอกค่าที่ได้ (ขึ้นครั้งเดียว)
- ต้องเติมเครดิตก่อนใช้ที่เมนู **Billing**

### 2. ใส่ `.env.local`

```
ANTHROPIC_API_KEY=sk-ant-...
```

### ค่าใช้จ่าย

คิดตามจำนวนหน้าและความยาวเอกสาร ประมาณ **1–3 บาทต่อใบ**
ระบบเรียกชั้นนี้**เฉพาะตอนที่ชั้นก่อนหน้าอ่านไม่ครบ** ใบปกติจึงไม่เสียเงินเลย

อยากรู้ตัวเลขจริงก่อนเปิดใช้ ให้วัดด้วย `npm run try:ocr` (ดูหัวข้อถัดไป)

## วัดผลก่อนเปิดใช้จริง

ตั้งค่าเสร็จแล้ว **ควรวัดก่อน**ว่าคุ้มไหม ก่อนปล่อยให้พนักงานใช้

```bash
cd v2

# วัดเฉพาะ OCR
npx tsx --tsconfig tsconfig.json scripts/try-ocr-ai.ts ../../test/BL --drive

# วัดเฉพาะ AI (มีค่าใช้จ่ายตามจำนวนใบที่ทดสอบ)
npx tsx --tsconfig tsconfig.json scripts/try-ocr-ai.ts ../../test/BL --claude

# วัดทั้งคู่เทียบกัน
npx tsx --tsconfig tsconfig.json scripts/try-ocr-ai.ts ../../test/BL --drive --claude
```

สคริปต์เทียบกับ**เฉลยที่ตรวจด้วยตาแล้ว** และบอกค่าใช้จ่ายจริงต่อใบ
ไม่แตะฐานข้อมูล

### ตัวเลขฐานที่วัดไว้แล้ว

| กลุ่ม | ระบบปัจจุบัน |
| --- | --- |
| ใบ PDF ปกติ | **16/16 = 100%** |
| ใบสแกน | **0/29 = 0%** |

**ดูที่ใบสแกนเป็นหลัก** เพราะเป็นเหตุผลทั้งหมดที่ทำเรื่องนี้
ถ้าวิธีใหม่ยังได้ 0 ก็ไม่ต้องเปิดใช้

และ**ดูว่ามีช่องไหน "ได้ค่าแต่ผิด" ไหม** — อันตรายกว่าค่าว่าง
เพราะคนกดบันทึกเร็วและมักไม่ทันสังเกต

## ใช้งานจริง

ตั้งค่าเสร็จแล้วไม่ต้องทำอะไรเพิ่ม — หน้ารับงาน (AN/BL) เรียกให้เอง

```
เลือกไฟล์
  → กรอบ + ตัวอ่านอัตโนมัติอ่านก่อน (ฟรี เร็ว)
  → ครบช่องสำคัญ = จบ
  → ยังขาด = ขึ้น "กำลังลองอ่านด้วย OCR / AI..." แล้วเติมให้
```

ค่าที่มาจากชั้น OCR/AI จะขึ้นข้อความเตือนว่า
**"ค่าจากเครื่องอ่าน ควรตรวจทุกช่องก่อนบันทึก"** พร้อมบอกค่าใช้จ่ายที่เกิดขึ้น

### บนเซิร์ฟเวอร์จริง (Vercel)

ใส่ค่าเดียวกันที่ **Settings → Environment Variables** แล้ว redeploy
ค่าใน `.env.local` มีผลเฉพาะเครื่องตัวเอง

---

## ปิดชั้นไหนก็ได้

ลบค่าใน `.env.local` (หรือบน Vercel) ชั้นนั้นจะถูกข้ามไปเงียบ ๆ
ระบบกลับไปใช้กรอบ + ตัวอ่านอัตโนมัติเหมือนเดิม ไม่พัง
